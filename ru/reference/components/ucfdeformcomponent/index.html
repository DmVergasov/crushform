UCFDeformComponent

МОДУЛЬCrushformЗАГОЛОВОКCFDeformComponent.hРОДИТЕЛЬUActorComponent

Вмятины и износ краски одного эктора, корневой компонент которого — его симулируемое тело. Без профиля ничего не делает, кроме того, что OnWheelSurfaceChanged и GetWheelSurface не требуют ни профиля, ни сетки грязи. Решётка натягивается на коллизию тела в пространстве корневого компонента при начале игры.

Сервер держит настоящую решётку и публикует её чанками 4x4x4. Клиент, который симулирует тело, отправляет свои удары на сервер и сразу рисует их как предсказание; все остальные клиенты рисуют полученные чанки.

bool FillDirt(const FCFDirtValues& Floor)
LOCALC++ ONLY

Поднимает грязь этого тела как минимум до этих значений по каналам (0..1), как её оставляет длинная поездка; измеряется от земли под колёсами так же, как при езде: максимум у линии земли, с истончением вверх по форме каждого канала в профиле; канал брызг снова полон вокруг каждой оси. Тело в воздухе измеряется от своего низа. Только на этом инстансе: грязь никогда не передаётся по сети. Вспомогательное средство для отладки; колёса продолжают добавлять и сбрасывать грязь, как и раньше. Возвращает false там, где грязь не отрисовывается. Собственного OnDirtChanged не отправляет: об изменении сообщит следующее обновление грязи.

bool ApplyLatticeHit(const FCFHitInput& Hit)
C++ ONLY

Применяет удар, заданный в пространстве решётки, как если бы физика сообщила его здесь: на авторити — к решётке, на клиенте, который симулирует тело, — как предсказание, которое он сообщает. Возвращает false, если этот инстанс не может применять удары к владельцу, и когда профиль не допускает вмятин.

bool ApplyWorldHit(const FVector& WorldPoint, const FVector& WorldNormal, float DeltaV)
C++ ONLY

Удар, заданный в мировом пространстве геймплеем, а не физикой, например объект, который тело разрушило, не касаясь его. WorldPoint лежит на теле или рядом с ним; WorldNormal может смотреть в любую сторону; DeltaV в м/с. Правила для инстансов те же, что у ApplyLatticeHit; также false, если точка вне решётки или удар слишком слабый для вмятины, и когда профиль не допускает вмятин.

void DentFromBrokenUnit(UPrimitiveComponent& Body, const FVector& UnitPoint, const FVector& VelocityCmS, float SpeedFraction)
C++ ONLY

Разрушаемый элемент поддался под Body, который физически никогда не касается элементов: вмятина на теле в точке, ближайшей к UnitPoint, с силой SpeedFraction от скорости тела в элемент. Ничего не делает на инстансе, который не симулирует тело (IsImpactSourceHere): там вмятину передаёт собственный отчёт симулирующего клиента. Body не const, так как трассировка компонента не const.

bool CrushByPlane(const FVector& WorldPoint, const FVector& WorldDirection, float Softness, float Bulge)
AUTHORITYC++ ONLY

Только для авторити: вдавливает плоскую пластину в тело; её плоскость проходит через WorldPoint и движется вдоль WorldDirection (FCFLattice::ApplyPlaneCrush; Softness в см, Bulge как доля толчка). Не предсказывается: клиенты видят его по мере прихода чанков. Возвращает false на инстансе без авторити над решёткой, когда профиль не допускает вмятин и когда ничего не сдвинулось.

float GetGivingWayMass(const UPrimitiveComponent* OtherComp, FName BoneName)
C++ ONLY

Масса, которая поддаётся при ударе по OtherComp, кг: ударенное тело вместе с тем, что его толкает, его приваренные части, остальной скелет, симулируемое тело эктора, к которому оно прикреплено (сочленённая стрела автомобиля). 0 для тела, которое не двигается: статического, кинематического или не симулируемого.

float GetEnergyScale(float OwnMass, float GivingWayMass)
C++ ONLY

Пересчёт изменения собственной скорости тела при ударе в скорость в неподвижную стену, которая принимает ту же энергию: sqrt(1 + OwnMass / GivingWayMass), отношение ограничено CF::MaxGivingWayMassRatio. 1, когда ничего не поддаётся.

float GetSupportSpeed(const UWorld* World, float NormalZ)
C++ ONLY

Изменение скорости (см/с), которое контакт с нормалью такого Z сообщает телу, лежащему на нём, на каждом шаге физики, лишь чтобы удержать его: часть импульса каждого удара и весь импульс лежащего тела. Удары приходят по одному на шаг солвера, поэтому шагом служит асинхронный фиксированный шаг, когда физика тикает асинхронно, иначе шаг кадра, как его ограничивает движок.

bool ComputeLatticeLayout(const AActor& Owner, const FCFDeformHostCaller& Host, const UCFProfile& Profile, FCFLatticeLayout& OutLayout)
C++ ONLY

Решётка, которую Profile задаёт для Owner: какие меши деформируются, бокс, охватывающий коллизию тела, и сетка по этому боксу. Возвращает false, если у владельца нет корневого компонента или ни один меш не деформируется. Запрашивает Host, который вызывающий код привязывает к политике владельца, поэтому работает до BeginPlay, в том числе на превью-экторе Blueprint.

bool IsDeformEnabled() const

const FCFBodyCollision& GetBodyCollision() const

void CarryLooseParts(const FTransform& FromRoot)
C++ ONLY

Вызывайте сразу после телепортации владельца, передавая трансформ корня из момента непосредственно перед ней. Качающаяся деталь — это отдельное тело, которое телепортация оставляет позади, и её джоинт оторвал бы её для всех: эта функция переносит каждое такое тело вместе с телом, с новой скоростью корня, так что ошибка джоинта не остаётся.

FTransform GetLatticeToWorld() const
PUREC++ ONLY

Преобразует из пространства решётки в мировое пространство, для отладочной отрисовки.

PhysicalMaterial или состояние касания земли у колеса изменилось с момента последнего сообщения, а также при первом появлении колеса: проверяется каждый кадр на инстансе, который не является выделенным сервером, независимо от того, рисуется ли грязь. Изменение только SurfaceSpeed срабатывания не вызывает: событие несёт текущее значение. Колесо в воздухе сообщает PhysicalMaterial, равный null, поэтому смена материала, пока колесо в воздухе, ничего не вызывает. Только для колёс, указанных host-объектом (FCFWheelContact::WheelIndex).

Повреждение на этом инстансе изменилось: Get Damage Zones отличается от того, что несло последнее событие. Читается не чаще одного раза за кадр, после изменения решётки, на каждом инстансе (в том числе на выделенном сервере), по повреждению, которое подтвердил сервер: удар, который этот инстанс предсказывает, не срабатывает, пока сервер его не подтвердит. Ремонт срабатывает с нулями; игрок, подключившийся позже, получит событие, когда реплицированные чанки построят решётку. Пока мир на паузе, ожидается первый кадр без паузы. Состояние до первого события читайте через Get Damage Zones.
