СПРАВОЧНИК/КОМПОНЕНТЫ

Компоненты

  • UCFBreakableInstancesComponent

    Разрушаемые элементы на ядре элементов Crushform, уложенные владельцем: ISM-инстансы, которые их показывают, раскладка, в которой они стоят, респаун на стороне сервера и, для определений, которые этого требуют, разрушение от любого тела.

  • UCFBreakableUnitsComponent

    Реплицируемое ядро набора разрушаемых элементов; каждый проходит уровни от 0 (целый) до MaxLevel (разрушен окончательно).

  • UCFChaosVehicleAdapterComponent

    Адаптер автомобиля для колёсного автомобиля Chaos (AWheeledVehiclePawn с UChaosWheeledVehicleMovementComponent): его колёса берутся из WheelSetups и состояний колёс компонента движения, а не из списка и трассировок.

  • UCFDeformComponent

    Вмятины и износ краски одного эктора, корневой компонент которого — его симулируемое тело.

  • UCFEngineAudioComponent

    Звук двигателя: петли UCFEngineSoundProfile, плавно сводимые и меняющие высоту тона в зависимости от оборотов двигателя, громче под нагрузкой, со стартером при прокрутке двигателя, нарастанием при запуске, затуханием и звуком глушения при остановке.

  • UCFGlassComponent

    Стеклянная панель кузова Crushform: меш владельца, который трескается и разбивается вместе с UCFGlassUnitsComponent владельца.

  • UCFGlassUnitsComponent

    Стекло одного кузова Crushform: каждый UCFGlassComponent владельца — это элемент с двумя уровнями (треснувший, разбитый), пронумерованный по имени, чтобы все инстансы совпадали.

  • UCFHingeComponent

    Шарнир навесной детали кузова: двери, капота, крышки багажника, бампера.

  • UCFImpactFeedbackComponent

    Превращает удары твёрдого тела одного примитива в события отклика на удары.

  • UCFNetImpactFeedbackComponent

    Сообщает об ударах корневого тела владельца только там, где это тело симулируется (ICFDeformHost::IsCrushformImpactSourceHere host-объекта владельца, найденного через UCFHostRegistry; без host-объекта — авторити): в остальных местах тело подводится к реплицируемому состоянию, а его контакты появляются и исчезают вместе с коррекциями.

  • UCFPartImpactFeedbackComponent

    Проигрывает удары навесных деталей владельца (UCFHingeComponent).

  • UCFPropContactComponent

    Позволяет телу владельца разрушать разрушаемые элементы, сквозь которые оно проезжает, на инстансе, который его симулирует.

  • UCFRollingAudioComponent

    Звук качения шины для каждого колеса.

  • UCFRollingFXComponent

    Эффект качения колёс тела (пыль, грязь, брызги): один компонент Niagara на каждое колесо, о котором сообщает host-объект; создаётся при первой необходимости.

  • UCFTireComponent

    По одному на автомобиль.

  • UCFVehicleAdapterComponent

    Подключает Crushform к автомобилю без кода.

  • UCFVehicleChaseCameraComponent

    Камера слежения в стиле GTA для пешки-автомобиля.
