МИР/ОТКЛИК НА УДАРЫ

Отклик на удары

Что это делает

Заголовок раздела «Что это делает»

Когда автомобиль врезается в стену, забор, дерево или окно, он издаёт звук и выбрасывает искры. Когда разрушаемый фрагмент приземляется, он издаёт глухой стук. Отклик на удары — та часть Crushform, которая всё это проигрывает. Она превращает удар в событие удара, находит, как это событие должно звучать и выглядеть, и проигрывает его в месте удара.

Если включена консольная переменная LogHits, плагин сообщает о каждом ударе, который он оценивает. В сеансе игры в редакторе каждый удар оставляет маркер на 5 секунд: сферу в точке удара со стрелкой вдоль нормали поверхности. Маркер зелёный, когда удар проигрывается, жёлтый — для удара внутри устойчивого контакта, и красный — для удара ниже минимума. Каждый оценённый удар также пишет одну строку в лог, в категорию LogCrushformImpact, в таком виде:

Вердикт — played, below minimum или steady contact, suppressed.

Как это работает

Заголовок раздела «Как это работает»

Каждый удар — это gameplay-тег, например Crushform.Impact.Prop.Break.Wood, который проигрывается в точке. Остальное делает UCFImpactFeedbackSubsystem:

  1. Он находит строку для тега в активном наборе ударов. Если в наборе нет строки для этого точного тега, используется строка ближайшего родительского тега, у которого она есть. Если ни одна строка не подходит, ничего не проигрывается.
  2. Он проигрывает один звук из строки, выбранный случайно, и порождает эффект Niagara строки с заданным параметром Intensity.
  3. Он масштабирует громкость между значениями Volume by Intensity строки и выбирает высоту тона из её Pitch Range.
  4. Он применяет фильтры строки: удар ниже Min Intensity ничего не проигрывает, источник, который недавно проигрывал звук, ждёт свой Cooldown Seconds, а пока заняты Max Concurrent Voices строки, новый удар проигрывает эффект, но без звука.

Набор ударов — ассет данных UCFImpactFeedbackSet. Набор проекта по умолчанию — /Crushform/Impact/DA_CF_ImpactFeedback, со строкой для каждого тега плагина. Проект может создать свой набор и указать его в Default Set.

Удары исходят от компонентов, которые сидят на теле. Вы добавляете их в меню Add редактора Blueprint, где все три перечислены в разделе Custom, а не в Crushform:

  • UCFImpactFeedbackComponent сообщает об ударах наблюдаемого примитива с Event Tag, который ему задан (по умолчанию Crushform.Impact.Hit). Он ничего не наблюдает, пока вы не передадите ему примитив через SetObservedPrimitive, это только C++. Удар оценивается по импульсу на килограмм тела. Ниже Min Impulse Per Kg (50) он молчит, а в полную силу звучит при Impulse Per Kg for Full Intensity (600). Устойчивый контакт, например тело, опирающееся на землю, не повторяет удар.
  • UCFNetImpactFeedbackComponent сам наблюдает корневой примитив своего владельца и также передаёт удар другим игрокам. Передача обычно ждёт не меньше Min Relay Interval Seconds (0,5 с) и приходит раньше для заметно более сильного удара.
  • UCFPartImpactFeedbackComponent проигрывает удар навесной детали, когда она достигает конца своего хода. Деталь, которая ударяется о закрытый конец, проигрывает Slam Event Tag, по умолчанию Crushform.Impact.Part.Slam. Деталь, отброшенная далеко в открытый конец, проигрывает Open Slam Event Tag, по умолчанию Crushform.Impact.Part.Slam.Open, а набор ударов без строки для этого тега проигрывает строку Part.Slam.

Автомобиль получает эти компоненты от своего адаптера. Определение разрушаемого объекта называет свои теги, а пустой тег проигрывает тег плагина по умолчанию.

Настройка

Заголовок раздела «Настройка»

Здесь используется поставляемый набор, а затем создаётся собственная строка.

  1. В Content Browser набор по умолчанию находится в Plugins › Crushform Content › Impact.
  2. Откройте DA_CF_ImpactFeedback. Его список Entries содержит по одной строке на тег. Найдите строку Crushform.Impact.Prop.Break.Wood, чтобы увидеть, что хранит строка: Sounds, Effect, Attenuation, диапазоны громкости и высоты тона и фильтры.
  1. Чтобы сделать свой набор, выберите Add › Miscellaneous › Data Asset, укажите класс CFImpact Feedback Set и добавьте строку в Entries. Задайте её Event Tag равным нужному тегу и заполните её звуки и эффект.
  2. Откройте Project Settings › Plugins › Crushform Impact Feedback. Задайте Default Set равным вашему набору. Набору нужны только строки для тегов, которые вы хотите слышать. У тега без строки используется строка его ближайшего родителя, поэтому строка для Crushform.Impact покрывает все теги, у которых своей строки нет.
  3. Чтобы дать автомобилю его удары, оставьте включённым Impact Feedback на адаптере, как это есть по умолчанию. Его CF_ImpactFeedback проигрывает Impact Event Tag адаптера. CF_PartImpactFeedback сохраняет собственные теги, и адаптер создаёт его только при включённом Dirt and Dents. Таблица компонентов описана на странице Основные понятия.

Использование

Заголовок раздела «Использование»

В своём проекте Blueprint проигрывает удар узлом Play Impact. Он принимает тег, точку, нормаль (по умолчанию вверх), интенсивность от 0 до 1, поверхность и необязательный источник. Удары от одного источника делят общую задержку. График ниже проигрывает удар поломки дерева в точке эктора, когда срабатывает пользовательское событие.

Play Impact проигрывается только на инстансе, который его вызывает, а на выделенном сервере не проигрывается вовсе. Игра, в которой каждый игрок должен его слышать, вызывает его на каждом инстансе, например из multicast-события.

То же в C++ использует функцию библиотеки, с тегами из CFImpactTags. Блоку нужен модуль CrushformImpact в вашем Build.cs; список модулей есть на странице Установка.

Сигнатура: static void PlayImpact(const UObject* WorldContextObject, FGameplayTag Tag, FVector Location, FVector Normal = FVector::UpVector, float Intensity = 1.f, EPhysicalSurface Surface = SurfaceType_Default, const UObject* Source = nullptr). UCFImpactFeedbackSubsystem::Get(WorldContext)->PlayImpact(FCFImpactEvent) — тот же вызов уровнем ниже, для кода, который строит событие сам.

Проверка работы

Заголовок раздела «Проверка работы»

В любой сборке, кроме Shipping, откройте консоль клавишей тильда.

  • crushform.Impact.LogHits 1 включает маркеры. Въедьте седаном в стену, забор или дерево. Каждый оценённый удар оставляет маркер примерно на 5 секунд: зелёный для удара при контакте, который проигрывается, жёлтый для удара внутри устойчивого контакта и красный для удара ниже минимума. Чтобы их выключить, используйте crushform.Impact.LogHits 0. По умолчанию значение 0.
  • stat CFImpactFeedback показывает циклы ударов.
  • Ударьте автомобилем о стену. Вы слышите звук и видите эффект в месте контакта.

Устранение неполадок

Заголовок раздела «Устранение неполадок»

На выделенном сервере ничего не проигрывается, или другие игроки ничего не слышат

Заголовок раздела «На выделенном сервере ничего не проигрывается, или другие игроки ничего не слышат»

Причина. Выделенный сервер вообще не проигрывает ударов. Вызов Play Impact проигрывается только на инстансе, который его делает. Удары от компонента доходят до других игроков только через UCFNetImpactFeedbackComponent, который их передаёт.

Решение. Вызывайте Play Impact на каждом инстансе, который должен это слышать. Для ударов тела, которые должны слышать другие игроки, используйте на нём UCFNetImpactFeedbackComponent.

Тег ничего не проигрывает

Заголовок раздела «Тег ничего не проигрывает»

Причина. В активном наборе нет строки для этого тега или для любого из его родителей, поэтому UCFImpactFeedbackSet::FindEntry ничего не находит. Компонент или адаптер, у которого тег очищен вручную, тоже ничего не проигрывает.

Решение. Добавьте в набор строку для тега или строку для его ближайшего родителя. Верните тег на компонент или адаптер либо оставьте поле пустым, чтобы проигрывался тег плагина по умолчанию.

Тело, к которому я добавил компонент, молчит

Заголовок раздела «Тело, к которому я добавил компонент, молчит»

Причина. Здесь два случая. UCFImpactFeedbackComponent не наблюдает ни одного примитива, пока в C++ не вызван SetObservedPrimitive, поэтому компонент, добавленный только в Blueprint, молчит. UCFNetImpactFeedbackComponent наблюдает корневой примитив своего владельца, и если корень не является примитивом, он пишет эту строку и молчит:

Решение. Для базового компонента передайте ему примитив из C++ через SetObservedPrimitive. Для тела, которое должны слышать другие игроки, используйте UCFNetImpactFeedbackComponent и убедитесь, что корневой компонент владельца является примитивом, например мешем тела.

Удар молчит или проигрывает только эффект

Заголовок раздела «Удар молчит или проигрывает только эффект»

Причина. Удар ниже Min Impulse Per Kg (50) или ниже Min Intensity строки, поэтому он молчит. Либо все Max Concurrent Voices строки заняты, и тогда удар проигрывает эффект без звука.

Решение. Уменьшите Min Impulse Per Kg или Min Intensity для строки либо увеличьте Max Concurrent Voices. Включите crushform.Impact.LogHits 1, чтобы увидеть, краснеет ли удар (ниже минимума) или вообще был оценён.

Устойчивый контакт снова и снова проигрывает удар

Заголовок раздела «Устойчивый контакт снова и снова проигрывает удар»

Причина. Компонент проигрывает новый удар, только когда удар — это всплеск внутри его контакта: его импульс не меньше Contact Spike Ratio (2) текущего импульса. Контакт, который сохраняет свой импульс, не повторяется. Контакт, который прерывается дольше Contact Gap Seconds (0,1 с), считается новым.

Решение. Увеличьте Contact Gap Seconds выше нескольких шагов физики, если один удар распадается на несколько. Оставьте коэффициент всплеска по умолчанию, если устойчивый контакт всё же повторяется.

О поломках, из которых возникают эти удары, см. Заборы и объекты и Разрушаемые деревья и столбы. Собственные звуки удара автомобиля задаются на его адаптере, описанном в Основных понятиях.
