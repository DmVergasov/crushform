VEHICLE/ENGINE SOUND

Engine sound

What it does

Section titled “What it does”

The engine sound plays the engine of a vehicle. It crossfades a set of loops, each recorded at one engine speed, and pitches them to the engine’s speed in the game. Under load the engine is louder than when it coasts. The Crushform Engine Audio component plays the sound. The Vehicle adapter and the Chaos adapter create one for the vehicle, as CF_EngineAudio.

How it works

Section titled “How it works”

Loops. A UCFEngineSoundProfile holds the loops, as layers. A layer is one looping sound, the engine speed it was recorded at, and its volume. The component sorts the layers by speed. It fades between the two loops around the engine’s speed, and pitches each loop to the speed in the game. The pitch stays between Min Pitch and Max Pitch. The audio device limits pitch to 0.4 to 2.0 by default, so these two values work inside that range.

Load. With no throttle the engine plays at Coast Volume. With full throttle it plays at full volume. The volume moves between the two as the load changes.

Run state. The component asks the vehicle’s engine host once a frame for its state: off, cranking or running. While the engine cranks, the Starter Sound loops and the engine loops stay silent. When the engine runs, the loops rise over Start Fade Seconds. When it stops, they fade over Stop Fade Seconds, and the Shutdown Sound plays once.

Earshot. The engine plays only while a listener is within the range of the profile’s Attenuation. Out of earshot the sounds stop. When a listener comes back, the engine is heard as it is at that moment, without a rise or a shutdown it missed.

Cabin. A listener inside the cabin hears the engine quieter and duller. The adapter’s SetCabinMuffled muffles the engine too. A component on its own calls SetCabinMuffling.

Presentation only. The engine sound is silent on a dedicated server, because nothing there hears it. Without an Attenuation on the profile, the sound stays off, and the log says so.

Set it up

Section titled “Set it up”

This example makes an engine sound for your own vehicle. The plugin ships a default profile, DA_CF_DefaultEngineSound, with its loops and an attenuation, so you can skip the profile and use it.

  1. In the Content Browser, click Add, choose Miscellaneous, then Data Asset, and pick CFEngine Sound Profile. Name it MyEngineSound in your project’s folder.
  2. Open the profile. Under Layers, add one entry for each loop. Set Sound to a looping sound, RPM to the engine speed it was recorded at, and Volume to its gain. Use a different RPM for each layer.
  1. Set Attenuation to a sound attenuation asset. The plugin’s SA_CF_Engine is the sample. Without one the engine stays silent.
  2. Optionally set Starter Sound (it must loop, and plays while the engine cranks) and Shutdown Sound (it must not loop, and plays once when the engine stops).
  3. Open Edit, then Project Settings, then Plugins, then Crushform Engine. Check that Engine Sound is on, and that Default Profile is the profile you want for vehicles that name none.
  1. On the vehicle’s adapter, set Engine Sound Profile to MyEngineSound, or leave it empty for the default. Set Engine Sound Offset to move the sound to the engine’s position. Turn on Engine Sound.

Saving the profile runs its checks. They report a profile with no layer, a layer with no sound or a sound that does not loop, two layers with the same speed, no attenuation, a minimum pitch above the maximum, and a shutdown sound that loops.

Use it

Section titled “Use it”

On a Blueprint, the usual task is to muffle the engine when the listener sits in the cabin. The graph gets the engine audio component from the adapter with Get Engine Audio on CF_Adapter, then calls Set Cabin Muffling on it with a volume scale of 0.5 and a low-pass cutoff of 1200 Hz. On a vehicle with the adapter, Set Cabin Muffled on the adapter instead muffles the rolling sound and the engine together, with the settings’ values or, when its override is on, the adapter’s own.

The same call in C++. Find the component on the vehicle, then call its function. The signature is the one in the header. Your module must list the Crushform modules in its Build.cs, as in Installation.

The engine’s host, the object that answers the engine state, is set in C++ with SetCrushformHost before the component begins play. Its explicit host wins over the registry’s host for the owner.

Key settings

Section titled “Key settings”

Profile values are on UCFEngineSoundProfile, settings are on UCFEngineSettings, and the adapter’s are on UCFVehicleAdapterComponent. Defaults are the code’s.

Check that it works

Section titled “Check that it works”
  1. Press Play and rev the vehicle. Then open the console and run stat CrushformEngine. The Engine Audio Tick time appears while the sound updates.
  2. Drive away from the vehicle. The engine fades as you leave the attenuation’s range, and returns as you come back.

The sound itself does not show in a screenshot. Judge it by ear.

Troubleshooting

Section titled “Troubleshooting”

The engine is silent, and the log says the profile has no Attenuation

Section titled “The engine is silent, and the log says the profile has no Attenuation”

Cause: The profile’s Attenuation is empty. Without it the engine sound stays off, with a warning.

Fix: Set Attenuation on the profile. The plugin’s SA_CF_Engine is the sample.

There is no engine sound, and no engine audio component on the vehicle

Section titled “There is no engine sound, and no engine audio component on the vehicle”

Cause: Either Engine Sound is off in Crushform Engine, or Engine Sound is off on the adapter. In both cases the adapter makes no engine audio component.

Fix: Turn on both switches, then play again.

The engine is heard only close to the vehicle

Section titled “The engine is heard only close to the vehicle”

Cause: The engine plays only while a listener is within the range of the profile’s Attenuation: its largest distance.

Fix: Raise the attenuation’s range, or check that the listener is where you expect.

There is no engine sound on the server

Section titled “There is no engine sound on the server”

Cause: The engine sound is presentation only. It is silent on a dedicated server, because the server has no listener.

Fix: This is expected. Hear the engine on a client.

Setting the host has no effect

Section titled “Setting the host has no effect”

Cause: SetCrushformHost is refused once the component has begun play, and the log says so.

Fix: Call SetCrushformHost before the component begins play.
