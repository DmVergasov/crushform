UCFBreakableDefinition

模块CrushformBreakable头文件CFBreakableDefinition.h父类UPrimaryDataAsset

一种可破坏单元：其完好网格体、烘焙的碎片以及破坏调节。

函数

AUTHORITY · 服务器，每个端LOCAL · 本机PURE · 只读
uint8 ResolveHitLevel(FName HitKind, float Strength, uint8 MaxLevel, uint8& OutResponseIndex) const
PUREC++ ONLY

外部命中（HitKind）所达到的等级（0 表示无）及其在 HitResponses 中的行（为 0 时为 CFBreakable::NoResponse）。MaxLevel 为该单元仍可提升到的最高等级。

bool IsIntactMeshRequired() const
PUREC++ ONLY

IsDataValid 是否要求 IntactMesh。若定义的碎块并非从网格体切割而来，则返回 false。

FGameplayTag GetFeedbackTag(ECFBreakableFeedbackKind Kind) const
PUREC++ ONLY

游戏为 Kind 类反馈播放的音效与特效所用的标签；为空时，宿主播放插件为该事件设置的标签（CFImpactTags）。

const FCFBreakableHitResponse* GetHitResponse(uint8 ResponseIndex) const
PUREC++ ONLY

HitResponses 中位于 ResponseIndex 处的行；对于 NoResponse 或超出范围的索引，返回 nullptr。

float GetBreakFeedbackIntensity(const FVector& ImpactVelocity) const
PUREC++ ONLY

破坏反馈强度，范围 0..1：ImpactVelocity 的速度（cm/s）除以 SpeedForFullBreakIntensityCmS，并限制在该范围内。

属性
