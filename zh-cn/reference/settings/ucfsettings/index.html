FCollisionResponseTemplate GetLoosePartCollision() const
PUREC++ ONLY

铰接部件在摆动或脱落后所采用的碰撞：取 Loose Part Collision Profile 的模板；若其为 None 或未指定配置文件，则使用插件自身的碰撞。插件自身的碰撞不需要项目中的配置文件或碰撞通道：它是一个阻挡世界、忽略 Pawn、车辆、摄像机、可见性射线检测、可破坏物及其他物理刚体（包括其他松脱部件）的物理刚体。无论哪种情况，铰链之后都会让车辆单向阻挡该部件。

int32 WheelCustomDataOffset = 34

车轮网格体四个污垢通道及其层级序号（CF::WheelData）所对应的第一个 Custom Primitive Data 索引。这是独立的偏移量：车轮从不携带形变数据块，而其轮胎通常会从索引 0 开始携带其他数据（轮胎形变即是如此），因此默认值为最后两个浮点数。修改此值时，编辑器会重新生成烘焙它的材质函数（Crushform.RebakeOffsets 可手动执行）；请保存这些材质函数以保留结果。

float ContactGapSeconds = 0.1f

车身在没有受到其他刚体撞击的情况下，最多能持续多少秒，超过后它的下一次撞击就算作一次新的接触（可造成凹陷）。叠放在另一刚体上的车身，每个物理步都会受到数倍于自身重量的求解器推出作用；这些撞击属于同一次接触，并且在其碰撞窗口期过后，只有出现尖峰时才会造成凹陷。比此时长更长的帧（即卡顿）会把这段时间延长到该帧结束之后。

FName LoosePartCollisionProfile

铰接部件摆动或脱落后所采用的碰撞配置文件。None（Reset to Default）表示使用插件自身的碰撞，它不需要项目中的任何配置（参见 GetLoosePartCollision）。此处指定的配置文件应阻挡世界并忽略 Pawn。无论其对车辆的设定如何，铰链都会让该部件对车辆单向阻挡：车辆会托住它并将其推开，而车辆不会受到任何反作用力。

分类
Loose Parts
float SwingDamping = 1.0f

摆动部件绕其铰链的阻尼，作为关节的扭转速度驱动。它同时也会对 Swing Spring 施加阻尼：该驱动两者共用一个 Damping。

默认值
1.0f
分类
Loose Parts
float SwingSpring = 0.0f

将摆动部件拉回闭合姿态的弹簧，取关节扭转驱动的刚度，与其质量无关（这是加速度驱动，按 p.Chaos.JointConstraint.AngularDriveStiffnessScale（1.5）缩放）。Chaos 会在部件绕销轴转动时，按其绕质心的转动惯量对其缩放：在边缘铰接的车门或引擎盖，回转的角加速度约为此值 1.5 倍的四分之一，单位为每弧度开度对应的 rad/s^2（固有频率约为此值 1.5 倍的平方根的一半，单位 rad/s），并受 Swing Damping 阻尼。依靠自身重量即可闭合的部件（如引擎盖）无需此弹簧；竖直销轴上的车门无需弹簧也会停留在摆开的位置；仅由一个安装点悬挂着的部件（如保险杠）则需要它将其拉回。修改后新建的关节会采用该值。0 表示无弹簧。

默认值
0.0f
分类
Loose Parts
float StopBounce = 0.0f

摆动部件行程两端止挡的弹性程度（关节两端共用一个扭转限制）。0：使用物理引擎的止挡，将部件牢牢固定。高于 0 时，止挡为一个弹簧，部件会先陷入其中，然后再被弹回：这一取值在刚超过 0 时仅约为其速度的 0.05，在 0.66 时约为四分之一，在 1 时约为一半。以 180 deg/s 猛然关上的车门，在取值 0.66 时会先越过闭合位置 4 度（以 720 deg/s 时为 15 度）。开启端也会过冲：取 0.66 时，以 180 deg/s 猛然甩开的车门会越过其 Open Angle 约 1.3 度。搁在止挡上的引擎盖会略微陷入其中：取 0.66 时为 0.2 度，取 1 时为 0.9 度。修改后新建的关节会采用该值。

默认值
0.0f
分类
Loose Parts
float BumpResponse = 0.0f

车身颠簸时，摆动部件额外获得的推力：车身在销轴处的加速度使部件绕销轴产生的转动，乘以此倍数，叠加在物理本身给予的推力之上。0：仅使用物理。仅在模拟该车身的端上生效，那里是其撞击源：在回放该车身的端上，网络修正会被误读为颠簸。在游戏线程上读取车身运动：在异步物理下，推力会滞后于颠簸，滞后时长为若干固定步（p.AsyncInterpolationMultiplier），而物理自身的部分则立即生效。稳定的加速度同样会产生推力：车身在跳跃中下落时，引擎盖会被掀起。摆动得越猛烈，部件就越早积累其 Shake Off Travel。每帧读取：修改后立即生效。

默认值
0.0f
分类
Loose Parts
float SwingStartKick = 90.0f

部件开始摆动时，朝其开启一侧获得的角速度（deg/s），使其略微打开。

默认值
90.0f
分类
Loose Parts
float SwingSettleTime = 1.0f

刚开始摆动的部件，在此秒数内其关节既不会撕裂，也不会被甩脱：导致其松脱的那次碰撞不会同时撕裂其关节。它不会延迟凹陷：被压溃超过脱落阈值的部件会立即脱落。此后，撞击可能撕裂悬挂中部件的关节，晃动也可能将其甩脱。

默认值
1.0f
分类

关节在稳定时间结束时仍可保持激活状态所能承受的、占铰链 Break Force 与 Break Torque 的比例。承受更大负载的关节保持未激活，直到其在连续四分之一秒内负载均未超过此比例后才会激活（CFHinge::ArmQuietTime）：被外力压住而固定在原位的部件会继续悬挂，而不会在稳定时间结束的瞬间被撕裂。应将其设为低于 1，以免刚好低于阈值的负载在一帧后激活一个随即撕裂的关节。0 表示不读取负载，直接激活。

float TornPartHoldMargin = 20.0f

另一辆车须距离因凹陷而被撕下的部件的闭合位置多近（厘米），才能将该部件保持在那里。碰撞时，车身会在另一辆车抵达该部件之前先发生凹陷；若在其仍位于该部件处时放手，该部件就会在两个对它而言都无限重的物体之间脱开，被弹飞或楔入自身车身。当该车移开到超过此距离的那一帧，部件即落下，在碰撞中通常一到两帧之内。0：仅当车辆接触其位置、或在 Torn Part Hold Lookahead 时间内逼近该位置，或该位置有物体占据时才会保持。仅车辆计入此余量：低位部件下方的地面，或车辆所靠的墙壁，永远不会移开。

20.0f

float TornPartHoldLookahead = 0.05f

正在逼近被撕下部件的车辆，视为已在其处的提前秒数：余量会按其逼近速度乘以此值而增加。碰撞时的接触会先于车身相碰而出现：凹陷将车门撕下时，另一辆车仍可能距离车门超过 20 厘米，而在几毫秒后便抵达该处。驶离的车辆则只按余量计算。
