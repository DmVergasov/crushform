FCFDirtChannelShape

模块Crushform头文件CFDirtTypes.h

FillDirt 与车轮接触如何将一个通道铺展到车身上：从地面向上的飞溅、绕车轮的弧形区域以及车轮后方的拖尾，各自拥有独立权重。权重为 0 即关闭该部分。

函数

AUTHORITY · 服务器，每个端LOCAL · 本机PURE · 只读
FCFDirtChannelShape MakeDefault(ECFDirtChannel Channel)
C++ ONLY

返回通道初始的形状。

属性

float SprayWeight = 0.0f

飞溅的权重，即从地面扬起的部分；0 表示关闭。

默认值
0.0f
分类
Spray
float SprayHeightReach = 0.6f

飞溅停止处相对于车身离地高度的比例。

默认值
0.6f
分类
Spray
float SpraySpread = 4.0f

车轮飞溅强度减半时距车轮的距离，以车轮半径为单位。

默认值
4.0f
分类
Spray
float SprayRearBias = 0.0f

车身尾部的额外飞溅，占节点原本所得量的比例。

默认值
0.0f
分类
Spray
float ArchWeight = 0.0f

轮拱的权重，即环绕每个车轴的球体；0 表示关闭。

默认值
0.0f
分类
Arch
float ArchScale = 1.6f

环绕车轴的轮拱球体半径，以车轮半径为单位。

默认值
1.6f
分类
Arch
float TailWeight = 0.0f

尾迹的权重，即每个车轮后方的条状痕迹；0 表示关闭。

默认值
0.0f
分类
Tail
float TailScale = 4.0f

车轮后方条状痕迹的长度，以车轮半径为单位。

默认值
4.0f
分类
Tail
