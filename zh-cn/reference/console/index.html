参考/控制台

控制台命令

插件在控制台中注册的命令和变量。帮助文本即源码中为每一项写的说明。

名称类别默认值帮助
Crushform.Debug变量绘制用于移动车身网格的损伤晶格节点及其之间的连线：0 关闭，1 仅显示已受损的节点，2 显示全部节点。近期撞击显示为带有法线箭头的蓝色球体。先关闭再打开，可重建缓存的节点掩码。
Crushform.DebugImpact命令击中最远 100 m 处的可受损 Actor：十字准星下的那个，或名称包含第二个参数的那个。参数：撞击的速度变化量，单位 m/s（默认 10），之后可以选择性地指定名称。
Crushform.DebugMode命令切换 Crushform 调试模式：启用自由摄像机和一个工具菜单，可对车身和道具进行凹陷、弄脏、清洗、修复和重置。
Crushform.DebugMode.AllowClients变量1服务器是为远程客户端（1）运行 Crushform 调试工具，还是仅为其自身的本地玩家（0）运行。
crushform.Impact.LogHits变量01 = 记录撞击反馈组件判定的每一次撞击：撞击者、它减去的支撑处冲量、强度（负值 = 低于最小值，静音）和撞击点，并在世界中以沿撞击法线的箭头绘制该点，持续数秒：绿色为已播放（特效在此生成），黄色为持续接触，红色为低于最小值。
Crushform.RebakeDirtOrder命令按项目设置中的污垢层顺序（Dirt Layer Order，以及污垢通道的 Blend 和 Z Order）重建 MF_CF_Paint 和 MF_CF_DirtAmount，并重新编译使用它们的材质。这些函数不会保存。
Crushform.RebakeOffsets命令使用项目设置中的值，重新生成烘焙 Custom Data Offsets（Custom Data Offset、Wheel、Tire 和 Glass Custom Data Offset）的插件材质函数，并重新编译使用它们的材质。这些函数不会被保存。
Crushform.RepairAll命令将本机持有损伤数据的每个可受损 Actor 恢复原状。在服务器上运行，可为所有玩家修复它们。
Crushform.RewireLooks命令将外观设置（Body Dirt Look、Wheel Dirt Look、Glass Crack Look）应用到项目中所有调用 Crushform 污垢或玻璃函数的已保存材质。材质会被重新编译，且不会保存。
Crushform.ShowCollision变量以线框绘制每个可受损车身当前具有的碰撞：洋红色为其根部刚体的形状（包括跟随凹陷变化的块），白色为其松脱的铰接部件的形状。引擎的 show collision 绘制的是设计时的形状，凹陷从不改变这些形状。0 为关，1 为开。
Crushform.ShowZones变量以方块形式绘制每个可受损车身的刚度区域：蓝色为软，绿色为普通，红色为硬，并标注刚度倍数和深度上限。0 关闭，1 开启。
Crushform.Stats命令打印当前使用的图集槽位，以及本世界中每个可受损 Actor 的计数器。
Crushform.Tire.Debug变量0Crushform：轮胎预算调试。1 = 显示屏幕内计数，2 = 另外显示每个形变器的射线和每个轮胎的层级。
Crushform.Tire.Enable变量1Crushform：在车轮预算下的轮胎软形变。0 = 每个轮胎都恢复为圆形。在 Project Settings > Plugins > Crushform Tire 中设置；此变量会覆盖它。
Crushform.Tire.Hysteresis变量0.15fCrushform：被授予的轮胎在半径、排名和细节层级的边界上放宽的比例，使处于边界上的轮胎不会忽隐忽现。取值范围 0 到 0.9。在 Project Settings > Plugins > Crushform Tire 中设置；此变量会覆盖它。
Crushform.Tire.LodDistance1变量1500.0fCrushform：距离（厘米），超过它后轮胎使用更稀疏的射线扇形（细节层级 1）。在 Project Settings > Plugins > Crushform Tire 中设置；此变量会覆盖它。
Crushform.Tire.LodDistance2变量3000.0fCrushform：距离（厘米），超过它后轮胎使用最稀疏的扇形，并与简单碰撞进行检测（细节层级 2）。在 Project Settings > Plugins > Crushform Tire 中设置；此变量会覆盖它。
Crushform.Tire.MaxWheels变量30Crushform：同时允许形变的轮胎数量。本地玩家自己的车辆及与之耦合的一切始终会形变，即使超过此上限也是如此；剩余名额按屏幕内优先分给最近的其他轮胎。在 Project Settings > Plugins > Crushform Tire 中设置；此变量会覆盖它。
Crushform.Tire.OnScreenTolerance变量0.5fCrushform：车轮自上次在屏幕上被绘制起，仍被视为在屏幕内的秒数。在 Project Settings > Plugins > Crushform Tire 中设置；此变量会覆盖它。
Crushform.Tire.Radius变量4000.0fCrushform：距摄像机的距离，单位厘米，其他车辆的轮胎在此范围内可以形变。在 Project Settings > Plugins > Crushform Tire 中设置；此变量会覆盖它。
Crushform.Tire.UpdateInterval变量0.25fCrushform：两次轮胎预算处理之间的秒数。在 Project Settings > Plugins > Crushform Tire 中设置；此变量会覆盖它。
Crushform.WashAll命令Washes the dirt off every damageable actor this machine holds the damage of; the dents stay. Run it on the server to wash them for every player.
