UCFVehicleAdapterComponent

MODULECrushformVehicleINCLUDECFVehicleAdapterComponent.hPARENTUActorComponent

Blueprint: Crushform Vehicle Adapter

Puts Crushform on a vehicle without code. Added to any actor, it creates the dents and dirt, the glass, the tyres, the rolling sound and FX, the engine sound, the prop breaking and the impact feedback, and answers their questions about the vehicle: which machine simulates it, where its wheels touch the ground, which meshes are wheels, how its engine runs (the engine events below, which a subclass or a Blueprint overrides). Every machine creates the same components under the same names, so the replicated ones stand for each other. This generic adapter traces the wheels picked in Wheels; an adapter for a vehicle system (UCFChaosVehicleAdapterComponent) reads that system's wheels instead. A tyre that presses onto an obstacle pushes its wheel off it through the adapter, which holds the push on the wheel's mesh until the tyre asks again; a Blueprint that overrides SetCrushformTireWheelOffsets places the wheels itself and turns that push off. A wheel whose parent turns against the car, such as a steering knuckle, gets the wrong push while it turns.
